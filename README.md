# Pharmacy-Sales-Exploratory-Data-Analysis-
End-to-end Excel data analysis project analyzing annual pharmacy sales using Power Query, Power Pivot, and DAX. The project focuses on data cleaning, modeling, KPI analysis, and interactive dashboard reporting to generate actionable business insights.
## Project Overview
This project is an end-to-end data analysis of annual pharmacy sales data aimed at uncovering business insights, sales trends, and customer behavior. Using Microsoft Excel as the primary analytics tool, I performed data cleaning, data modeling, exploratory data analysis (EDA), and dashboard reporting to support data-driven decision-making.
## Objectives
To analyze pharmacy sales and supply data to:
- Evaluate overall business performance
- Identify top-performing products and locations
- Understand customer segmentation and purchasing behavior
- Provide actionable insights through interactive dashboards and KPI reporting
## Dataset Description
The analysis is based on three relational datasets
#### Sales Dataset
- Sales ID
- Transaction Date
- Customer ID
- Product ID
- Quantity Sold
- Sales Channel
#### Customer Dataset
- Customer ID
- Customer Name
- Gender
- Age
- City
- State
- Customer Type
#### Product Dataset
- Product ID
- Product Name
- Product Category
- Unit Cost
- Unit Selling Price

## Data Cleaning, Transformation and Modelling
- Using Power Query, I:
  - Standardized date formats and corrected column headers
  - Cleaned inconsistent and missing data
  - Created conditional columns for customer segmentation
- Using Power Pivot, I built a relational data model:
  - Sales[Product ID] → Product[Product ID]
  - Sales[Customer ID] → Customer[Customer ID]
  - Sales[Date] → Date Table[Date]
## DAX Measures and KPIs
Custom DAX measures were created to calculate key business metrics:
- Total Revenue
- Total Cost of Goods Sold (COGS)
- Total Profit
- Average Order Value (AOV)
- Total Quantity Sold
- Average Items per Order
## Dashboard & Data Visualization
An interactive Excel dashboard was designed to communicate insights effectively:
- KPI cards for executive-level summary
- Trend analysis charts (monthly revenue & profit)
- Comparative visuals by product category and state
- Slicers for dynamic filtering by location
- Clean, user-friendly layout for business stakeholders
## Key Insights and Use Cases
- Identified top-performing states and product categories by revenue
- Analyzed customer segments to understand purchasing patterns
- Evaluated sales channel performance
- Provided a consolidated annual sales performance report for management decision-making
